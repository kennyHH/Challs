# Enusec Challenges

A collection of cybersecurity challenges for learning and practice.

## Challenge List

| Name | Category | Difficulty | Description | Status |
|------|----------|------------|-------------|--------|
|Glitch in the matrix      |Forensics          |Easy/Medium            |Split the gif into frames, find flag in the one of the frames.              |   🟢     |
|Magic bytes     |Forensics          |Easy            |Corrupted JPG with changed magic bytes   ff d8 ff e0 -> de ad be ef           |  🔴      |
|I'm lost      |Forensics          |Easy            |JPG file with thumbnail replaced. The thumbnail contains the flag.             |   🔴     |
|Weird traffic      |Forensics          |Medium            |A `pcap/pcapng` with dnscat2 encrypted traffic. User finds C2 communication channel, decrypts the traffic and finds the flag             |   🔴     |
| Hidden melody     |Forensics          |Easy/Medium            |A song with morse code embedded in it. User decodes the morse code to find the flag.             |     🔴   |
|Message from space      |Forensics                    |Easy/Medium            |A user receives file containing SSTV signal . Decode to reveal the image containing flag             |    🔴    |
| A bombastic zip     |Misc          |Easy/Medium            |A zip bomb challenge. Each zip contains `password.txt` and another zip. 300 zip files in total. Last one contains `flag.txt`.             |    🔴    |
|Jump      |Misc                    |Medium            |A simple unity 2d platform game , where user has to modify/hack the game to make a jump.        |    🔴    |
