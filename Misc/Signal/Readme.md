# Project Slowscan

**Category:** Misc  
**Difficulty:** Easy
**Points:** 100

## Description

**INCIDENT REPORT - CLASSIFIED**

Subject: Unexplained personnel absence
Location: Royal Observatory, Edinburgh
Date: [REDACTED]

Observatory technician Sarah Kim reported discovering "structured visual transmissions" during routine deep space monitoring. Subject's notes reference  utilizing "Martin-1" for analysis.

Final recorded statement: *"The signal is definitely artificial. It's transmitting images the same way those old space missions used to send pictures back to Earth, but this is coming from interstellar space. Whatever sent this has been trying to show us something for a very long time."*

Subject failed to report for duty following this discovery. All primary analysis equipment experienced simultaneous failures. Single backup audio file recovered from emergency systems before complete data loss.

## Challenge

A WAV file containing SSTV signal (contains an image of an alien holding whiteboard with flag written on it.) 

## Files

- flag_image: `flag.png`
- Challenge file: `sstv_signal.wav`

## Objective

Decode the WAV file using an SSTV decoder and Martin-1 encoder.

## Solution

Android : Use Robot36 - SSTV Image Decoder to decode the image
Linux : Use QSSTV - https://github.com/ON4QZ/QSSTV
